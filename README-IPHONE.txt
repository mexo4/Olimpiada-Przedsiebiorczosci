OP Trainer v1.10.2 — iPhone / GitHub Pages

Wgraj na GitHub Pages wyłącznie zawartość folderu iphone-site.
Ten folder celowo nie zawiera oficjalnej bazy pytań OP (op-data.json).

1. Zastąp pliki strony nową wersją v1.10.2, w tym app.js, styles.css i sw.js.
2. Zamknij całkowicie OP Trainer na iPhonie, uruchom ponownie. Przy pierwszym otwarciu przez Internet PWA pobierze nową wersję.
3. Zachowujesz dotychczasową bazę i historię, jeśli otwierasz tę samą domenę, ścieżkę i instalację PWA (IndexedDB).
4. Jeśli baza nie pojawia się w aplikacji, zaimportuj prywatnie plik op-trainer-pytania.json z paczki Windows: Dane → Importuj własny JSON.

Zmiany: poprawne cofanie, edycja odpowiedzi i większe odstępy u góry (safe area) na iPhonie. Nie należy publikować bazy pytań w repozytorium strony.
