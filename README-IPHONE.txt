OP Trainer v1.7 - publiczna powloka PWA na iPhone

Ten folder NIE zawiera oficjalnej bazy pytan OP.
Wrzuc ZAWARTOSC folderu iphone-site do repozytorium GitHub Pages.

Baze przenosisz prywatnie:
1. Na PC: OP Trainer -> Dane -> Eksportuj baze.
2. Przenies plik op-trainer-pytania.json na iPhone (np. iCloud Drive/AirDrop).
3. W aplikacji na iPhone: Dane -> Importuj wlasny JSON.

Dzieki temu pytania nie sa publikowane w GitHub Pages i zostaja lokalnie na Twoim iPhonie.
